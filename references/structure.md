# 书评正文的结构与写法

范本是张启《AI时代的控制论：从理论源头到跨学科思潮》（新京报书评周刊，2026年3月），评的是金观涛、华国凡《控制论与科学方法论》。下面先给骨架，再逐部分说写法，最后拆解范本、列出范本的不足。

## 目录

## 1. 骨架与篇幅

```
# 主标题：副标题
书目信息（三四行）
导语（一段）
## 第一部分小标题        ← 源流与语境，约两成
## 第二部分小标题        ← 本书是什么，约五成
## 第三部分小标题        ← 局限与当下，约两成五
## 附录                  ← 见 appendix.md
```

三个小标题连起来应当是一条论证线：这门学问或这个题材从哪里来 → 这是一本什么样的书 → 它对今天意味着什么。第二、三部分的小标题要写成一个判断（如“极具中国底色的控制论著作”“引领AI时代的跨学科思潮”），后文的内容都在为这个判断举证；第一部分的小标题可以是主题（如“控制论的发展历史”）。书很厚、第二部分很长时，可以把横向定位单独成为一节，正文最多四个小标题。逐章梳理不另设小标题。

正文一般 6000—10000 字。逐章部分按章节的重要性分配篇幅，核心章节 500—900 字，次要章节 150—300 字；不要每章平均用力。

## 2. 标题、书目信息、导语

**标题**：主标题点出这本书和读者当下关切的交汇点，副标题概括全文的走向，常用“从……到……”。不要用“《某某》读书笔记”这种标签式标题。

**书目信息**：

```
《书名》
作者：某某（译者：某某）
某某出版社，2025年3月（本笔记页码均据此版）
```

**导语**：一段，80—200 字，回答两件事：这是一本什么书；为什么现在值得读。切入角度随书的类型变化，见 book-types.md。范本的导语先给这本书定位（80年代“三论”热潮的标志性成果），再说它时隔四十余年再版，最后落到在 AI 时代重温它的理由。导语不评价、不剧透结论，结尾那句话要在全文最后被呼应。

## 3. 第一部分：源流与语境

**开头的动作**：明确“先放下这本书”，转去讲它所处的领域或题材从哪里来。范本用一句过渡说明在讨论具体内容之前先谈起源与发展；每篇的过渡句自己写，不要照搬。

**写什么**（按书型调整，见 book-types.md）：
1. 领域或题材的起源：谁开创、最初关心什么问题、定义上有什么分歧。
2. 分化与流派：后来分成哪几支，各自往哪里发展。
3. 作者其人：学科背景、经历、思想来源，并说明这些如何体现在书的内容和风格里（范本写金观涛学化学而深研黑格尔、做过工人，又提到书中中国特色的例子来自华国凡对中医的研究）。
4. 成书时代的问题意识：那一代人在追问什么问题，这本书是对哪个问题的回应。结尾一句把时代和书扣上。

**选材原则：为后文埋伏笔。** 动笔前先列出后文要用到的东西：第二部分横向比较的对象、第三部分“以书观书”要反观的对象、局限部分要提到的人物和理论。背景必须先把它们交代出来，和它们无关的史实一律不写。范本在背景里交代了控制论定义上的分歧和第二序控制论，前者在第三部分被用来解释控制论为什么成了一种思潮而不是一门学科，后者在第二部分成了中西比较的参照物。

**事实要求**：人名、年代、书名、机构都要检索核实，并记进 notes/sources.md。推测性的说法加“可以想象”“大概”之类的限定。

## 4. 第二部分：本书是什么

### 4.1 总评与主线（一到两段）

先用一句话给全书定性：它是什么性质的书、在什么框架里、从什么切入点讨论什么问题。范本把这本书定为在自然辩证法框架内、以控制论为切入点讨论科学方法论的著作。

接着点明全书主线：贯穿各章的核心概念或核心问题是什么，各章如何分工、如何递进。这是范本没有明说、我们要补上的一步（见第 7 节）。

### 4.2 逐章梳理

每章一到两段，以“第X章……”开头，不设小标题。每章按下面五个动作写，可以视内容省略或合并：

1. **定位**：本章讨论什么，处在全书的什么位置。（范本：第二章讨论的是信息论中与控制论关系最密切的部分。）
2. **立场与预设**：作者站在什么立场、默认了什么前提。只指出，不评判，评判留到第三部分。常用句式：“需要指出的是，作者预设……”“这里作者的预设前提是……”。
3. **论证推进**：按原书的顺序复述论证，用“首先……随后……之后……接下来……进一步……最后……”显示先后，而不是把观点打散重排。
4. **关键原文**：每章引一到两处，选定义、判据、核心命题这类措辞本身重要的句子，不引修辞漂亮但可以转述的句子。原书本身有编号的条目（如五个条件），保留（1）（2）的编号写进段落。核心模型可以用一段长引文（块引用）。
5. **落点与过渡**：用本章的结论引出下一章。（范本写第二章，最后落在个体层面的概念需要放到整个系统中考察这一点上，自然引出第三章的系统论。）

逐章部分里，自己的看法只能以简短括注出现，如“（我认为崩溃后的系统也是一种稳定状态）”，每章最多一两处。也可以顺手提到作者在其他著作中对本章概念的应用（范本在超稳定系统之后提到《兴盛与危机：论中国社会超稳定结构》）。

### 4.3 横向定位（两到四段）

把这本书放到更大的图景里，依次做四件事：

1. **与同领域流派比较**：相同点、不同点、为什么不同（思想传统、时代条件、作者目的）。范本拿本书与西方第二序控制论比较：都把观察者纳入系统，但本书重点仍在有目的的过程，作者解释这是受马克思主义哲学和“经世致用”传统的影响。
2. **与同时代的平行思想比较**：别的领域有没有在差不多同时期独立得出相似想法的著作，用成书和出版年份作证据。范本把第三章对稳定结构的讨论和《自私的基因》对演化稳定状态的讨论并置，并给出两书的成书、出版和中译年份。这类判断要用“我觉得可以认为”之类的措辞。
3. **原创贡献**：这本书独有的东西是什么。说“某某领域没有”这种绝对判断之前，要有检索依据；没有依据就写成“据我所知”“在我读到的范围内”。
4. **作者的其他著作与后续思想**：书中的概念后来在哪里被应用或发展。

## 5. 第三部分：局限与当下

### 5.1 局限（一到两段）

四步：
1. **归因于时代**：先说明哪些局限来自当时的条件（资料、学术交流、知识进展），而不是作者的失误。
2. **善意重构**：对有争议的概念，先尝试把它和标准理论对照，找出相通之处，再说差别。范本把本书“可能性空间缩小”式的信息定义与香农信息量对照，指出两者其实相通，而且这种理解对概率控制有益。
3. **错过的对话**：指出作者本可以对话却没有对话的思想，用“倘若……会更有趣味”这类语气，并给出作者部分了解这一思想的证据（范本指出书中引用了波普尔的证伪原则，却没有回应波普尔对理性的批判）。
4. **按作者的初衷衡量**：最后提醒，这本来不是作者要做的事，不苛责。

### 5.2 以书观书（一段）

用这本书自己的框架去分析第一部分讲过的源流，或者某个相关现象，回收第一部分埋下的伏笔。范本把控制论这门学科本身看作一个系统，用书中的稳态、周期性震荡、自主修复机制，解释控制论为何始终没有成为一门稳定的独立学科，而是一股周期性回归的跨学科思潮。这一段是全文最见功力的地方，值得多花心思。

### 5.3 现实意义（两到三段）

1. 先检索与本书主题相关的当下进展，写具体的事、具体的时间，不写“百年未有之变局”式的泛称。
2. 把书中的概念翻译成一个具体行动者可以直接拿来用的问题清单。范本设想一个要引入 AI 的机构，借第四章的“质变”和第一、二章的“可观测变量、可控变量、信息过滤”，列出它的领导者该问的问题：当前是不是稳态，目标状态是不是稳态，渐变还是飞跃，靠什么指标决策。
3. 可以从微观（一个机构、一个人）推到宏观（行业、社会），但宏观部分同样要用书中的概念去分析，不要罗列宏观趋势。

### 5.4 结尾（一到两句）

回扣导语里的那句话，用“或许”这样的语气收住，不喊口号、不拔高。

## 6. 范本拆解

| 位置 | 范本做了什么 | 对应的动作 |
|---|---|---|
| 导语 | 定位为“三论”热潮的标志性成果；时隔四十余年再版；在 AI 时代重温的理由 | 这是什么书 + 为什么现在读 |
| 第一部分第1段 | 控制论的起源、维纳的定义、其他学者的不同定义，点明这为日后分化埋下伏笔 | 起源；埋伏笔 |
| 第一部分第2段 | 50年代起的分化：工程控制论、换了标签的 AI 研究、转向社会与哲学的一支、第二序控制论 | 分化与流派；为中西比较埋伏笔 |
| 第一部分第3段 | 金观涛的学科背景与经历、华国凡的中医研究、70—80年代知识青年的共同问题 | 作者与时代问题意识 |
| 第二部分开头 | 一句话定性：自然辩证法框架内的科学方法论著作 | 总评 |
| 第一至五章 | 每章：定位、预设、按顺序推进、引定义或判据（附页码）、过渡到下一章；括注里放极少的个人看法 | 逐章五个动作 |
| 第二部分最后两段 | 与第二序控制论比较；与《自私的基因》并置并用年份作证据；突变理论是原创贡献 | 横向定位 |
| 第三部分第1段 | 时代局限 → 信息定义与香农对照 → 错过与波普尔的对话 → 并非作者初衷 | 局限四步 |
| 第三部分第2段 | 用稳态和周期性震荡解释控制论学科自身的历史 | 以书观书，回收伏笔 |
| 第三部分第3—4段 | 机构引入 AI 时该问的问题清单；再推到宏观变化 | 现实意义 |
| 结尾 | 回扣“大变局中重温” | 首尾呼应 |

## 7. 范本的不足（写作时要避免）

1. **全书主线没有点破。** 从范本的复述看，控制、信息、组织都被表述为“可能性空间的缩小”，这很可能是全书的主轴，但范本没有明说。我们在总评之后要明确写出主线。
2. **个别论断过强又缺依据。** 范本断言突变理论是西方控制论研究里没有的。研究用的笔记要么给出依据，要么措辞留余地。
3. **宏观部分偏空。** 机构引入 AI 那段很具体，后面一段却只是罗列宏观趋势，没有和书中的概念扣上。
4. **细节有误。** 范本的图注把诺伯特·维纳写成了“罗伯特·维纳”；页码括注放在了引号里面。人名、年代、书名都要核对，页码括注放在后引号之外。
