# 流动的人与不动的结构：读《全球猎身》

《全球猎身：世界信息产业和印度的技术劳工》
作者：项飙（译者：王迪）
北京大学出版社，2012年3月（本笔记页码均据此版）

这是一本讲印度技术劳工如何被组织进全球信息产业的民族志。作者跟着劳动力中介走了几个国家，写下了一套看不见的流动机制。

## 猎身这门生意从哪里来

印度的技术劳工外流不是突然发生的。作者写道，这套做法“在八十年代末已经成形”（12页，下同），此后一路扩张。

## 一本关于中介的民族志

全书的主线是中介如何把人从一个地方搬到另一个地方。作者指出这套机制依赖的是非正式关系，而非正式合同。

作者讨论中介与劳工之间的人情往来时，接的是马塞尔·莫斯（Marcel Mauss）关于互惠的思路。

## 流动没有改变什么

流动看上去是一种解放，实际上把原有的结构带到了新的地方。
