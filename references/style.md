# 语言、引用与格式规范

## 1. 语言：平实自然

范本的语言很平实，读起来像一位认真读完书的人在讲给朋友听。照着下面几条写：

- 以短句和陈述句为主。一句话说一件事，长句拆开。
- 一段一个意思，段首第一句就说清这段讲什么。
- 用平常的动词和名词，少用形容词和副词，不堆修辞，不用排比，不用感叹号。
- 术语第一次出现时顺手解释一句（“第二序控制论，即把观察者、控制者纳入系统之中……”）。
- 判断直接说“我认为”“我觉得”；拿不准就用“或许”“似乎”“大致”“可以认为”。不要用“毋庸置疑”“显然”去替没把握的判断壮胆。
- 年份、页码、数量用阿拉伯数字；书名、篇名用书名号。
- 外国学者在正文里第一次出现时，写通行中译名，后面括注原名：诺伯特·维纳（Norbert Wiener）。之后再提到只写中译名。原名按学者本人发表著作时用的写法；用外文发表的华裔学者括注外文名，如黄宗智（Philip C. C. Huang）；日本学者的汉字名与中文写法相同时可以不注，如沟口雄三。原名和译名一样要检索核实，记进 notes/sources.md。
- 不写空泛的评价（“具有重要意义”“值得深思”）。想说一本书重要，就说它解决了什么问题、改变了什么看法。

对照示例：

| 不要这样写 | 改成这样 |
|---|---|
| 本书深刻揭示了控制论的底层逻辑，为我们提供了宝贵的启示。 | 作者把控制定义为缩小事物发展的可能性空间，后面几章都从这个定义出发。 |
| 不难发现，作者在第三章中鞭辟入里地剖析了稳定与不稳定的辩证关系，令人深思。 | 第三章讨论稳定与不稳定的关系。作者认为系统总是趋于稳定状态，除非发生周期性震荡或崩溃。 |
| 在人工智能飞速发展的大背景下，这本书无疑具有重要的现实意义。 | 不少机构在引入 AI 之前，并没有想清楚想达到什么状态、靠什么指标判断。书里讲质变的那一章，正好可以拿来问这些问题。 |
| 作者借用了维纳的反馈概念。（第一次提到维纳） | 作者借用了诺伯特·维纳（Norbert Wiener）的反馈概念。 |

## 2. 三种声音：原话、转述、自己的看法

一篇读书笔记里混着三种内容，必须让读者一眼分清：

| 内容 | 写法 |
|---|---|
| 作者原话 | 加引号，后面紧跟页码：“……”（23页） |
| 对原书的转述 | 用“作者认为”“作者指出”“作者提出”“作者把……称为”“作者的主要观点是”引出，不加引号 |
| 自己的看法 | 用“我认为”“我觉得”“在我看来”引出 |

规则：
- 不能把自己的解读写成作者的观点。转述时如果加入了自己的概括（例如“作者对信息的理解是以结果为导向的”），前面用“出于这种立场”“可以看出”之类的话提示这是概括。
- 第二部分逐章梳理时，自己的看法只用简短括注：“（我认为……）”，每章最多一两处；大段的个人评论放到横向定位和第三部分。
- 转述也要对得上原书：写完后抽查几处“作者认为……”，用 locate.py 找到原文确认没有曲解。

## 3. 引用格式

- **基本格式**：“原文”（23页）。页码括注放在后引号之外，用全角括号。
- **第一次引用本书**：“原文”（《书名》23页，下同），之后只注页码。
- **跨页**：（23—24页）。**前言等罗马数字页码**：（iv页）。**注释里的话**：（23页注1）。
- **没有页码的版本**（EPUB、DOCX、TXT）：注章节，“原文”（第三章）。
- **长引文**（一百字以上，或核心模型）：单独成段，用块引用，页码放在段末。
- **省略**：中间省略用“……”，省略前后都必须是逐字原文。不改动原文的任何字词和标点，原文里的错字照录，可在后面括注“（原文如此）”。
- **引文里的引号**：原文的双引号在引文中改为单引号‘’。
- **译著**：页码是译本的页码；关键术语可在引文后括注原文。
- **他书引文**（书中转引的、或背景部分引用的其他著作）：写明出处“（毛泽东《实践论》）”，并检索核实；verify_quotes.py 不核对他书引文，要自己负责。
- **引多少**：每章一到两处，全文一般 10—20 处。附录的引文索引可以多一些。

## 4. 格式

- 正文只用三到四个二级小标题；逐章部分不设小标题，每章以“第X章”起段。
- 正文不用列表、不用加粗。原书本身有编号的条目，写成段落里的（1）（2）（3）。
- 附录可以用表格和列表。
- 段落一般 150—500 字，超过 700 字考虑拆开。

## 5. 要避免的套话

check_style.py 会读取下面标记之间的清单，逐条检查书评正文。每行格式是“- 短语｜说明”，多个写法用“/”隔开，“re:”开头的是正则表达式。可以按需增删。检查到的不一定都要删：确实有具体含义的用法可以保留，但多数情况下删掉或换成具体的说法会更好。

- 深刻揭示/深刻地揭示/深刻阐述/深刻剖析｜空泛拔高，直接说揭示了什么
- 具有重要意义/具有重要的现实意义/具有重要的理论意义/具有十分重要｜说清楚意义在哪里
- 值得我们深思/引人深思/发人深省/令人深思/耐人寻味｜空泛
- 为我们提供了宝贵/提供了新的视角/提供了全新的视角/提供了独特的视角｜空泛
- 不禁让人/不禁感叹/让人不禁｜抒情腔
- 毋庸置疑/不言而喻/众所周知/显而易见｜替判断壮胆
- 值得注意的是/值得一提的是/需要强调的是｜多余的提示语
- 不难发现/不难看出｜多余
- re:在[^，。；]{1,15}的大背景下｜套话
- 从某种意义上说/在某种意义上/某种程度上来说｜含糊
- 底层逻辑/赋能/抓手/闭环/颗粒度/方法论层面/全方位/多维度/多层次｜流行词
- 娓娓道来/鞭辟入里/振聋发聩/醍醐灌顶/字里行间/跃然纸上/淋漓尽致/入木三分｜修辞堆砌
- 精彩纷呈/引人入胜/不可多得/经典之作/必读之作/堪称｜广告腔
- 智慧的结晶/思想的光芒/宝贵财富/时代的回响/历久弥新｜空泛拔高
- 一言以蔽之/总而言之/综上所述｜总结腔，正文结尾用回扣导语代替

- re:让我们[^。]{0,8}(一起|共同|看到|思考|走进)｜宣讲腔

- 难道不是/岂不是｜反问
- 可以说是/可谓是｜含糊
