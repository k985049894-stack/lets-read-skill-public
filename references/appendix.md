# Frontmatter 与附录：写给日后写论文、做研究的自己

正文是书评，附录是工具。附录可以用表格和列表，语言同样平实。附录里的每一条引文都要过 verify_quotes.py。

一份填好的完整样例见 `references/format-example.md`（内容为虚构，只看结构）。

附录还有第二个读者：日后把许多本书的笔记归并成跨书概念库的脚本。所以 frontmatter 和附录二、三、四的字段、列顺序和标签词表都是固定的，写完用 `check_meta.py` 校验。固定的只是容器，填什么仍然靠判断。

**标题层级固定如下**（与 format-example.md 一致）：

```
## 附录
### 附录一　阅读与引用说明
### 附录二　核心概念表
### 附录三　主题引文索引
#### 关于……（附录三的主题分组，比附录标题低一级）
### 附录四　延伸阅读
```

---

## Frontmatter（必有，文件最开头）

写在笔记正本（归档后是 `books/<书名>/<书名>.md`）最前面的 YAML 块，三道短横线包起来，前面不留空行。它是这本书在概念库里的身份证。

```yaml
---
book:
  title: 全球猎身：世界信息产业和印度的技术劳工
  author: 项飙
  translator: 王迪                  # 无译者写 null
  publisher: 北京大学出版社
  year: 2012
  edition: 2012年3月第1版            # 版次/印次，与附录一一致
  page_source: 印刷页码              # 印刷页码 | PDF页序 | 无
reading:
  date: 2026-10-09                  # 写完笔记的日期
  mode: 顺序通读                     # 顺序通读 | 并行阅读 | 重点阅读
  intensive: []                     # 重点阅读时填精读的章序号，如 [1, 3, 5]
  ocr: false
  quotes_verified: true             # verify_quotes.py 全部通过才写 true
concepts:                           # 与附录二逐行对应，顺序一致
  - name: 猎身                       # 作者的说法，照抄附录二第一列
    canonical: 猎身                  # 归并名；本书自创的概念就写同一个词
    aliases: [body shopping, 劳力中介]  # 原文词、其他译法、别的书的叫法；没有写 []
  - name: 坐板凳（benching）、板凳术    # 作者的说法，原样保留
    canonical: 板凳制度               # 归并名：别的书多半不这么叫
    aliases: [benching, 坐板凳, 板凳术]
topics:                             # 与附录三的 #### 分组标题逐条对应，顺序一致
  - 关于猎身的运作机制
  - 关于技术劳工的全球流动
  - 关于印度社会结构的延续
---
```

**第一条铁律：笔记里一律用作者的说法。** 正文、附录二、附录三，凡是出现概念名的地方，都照作者（或这个译本）怎么说就怎么写——「板凳术」就是「板凳术」，「非正式的IT部门」就是「非正式的IT部门」，不要替换成领域里的通行叫法。读书笔记是关于这一本书的文件，改掉作者的措辞，等于让笔记转述了一个他没说过的说法；日后回头查，也会对不上原书。`name` 就是这个说法，和附录二第一列逐字相同。

**`canonical`（归并名）是另一回事，只服务于跨书归并。** 它不出现在笔记正文里，只躺在 frontmatter 里，作用是让不同的书谈同一件事时能并到一页上。定名四条：

1. **领域里已有通行叫法的，`canonical` 写通行叫法。** 书里说「板凳术」，`name` 照写「板凳术」，`canonical` 写「板凳制度」。两者不同是正常的，不是错误。
2. **本书自创的概念，`canonical` 和 `name` 写同一个词。** 「猎身」「虚拟短缺」「印度三角」是作者的发明，没有别的通行叫法，也不该有——硬给它安一个"更通用"的名字，是把作者的贡献抹掉。
3. **外文概念的 `canonical` 用通行中译名，原文词放 aliases。** 同一概念有两个流行译法时，选一个做 `canonical`，另一个进 aliases。
4. **拿不准时优先沿用已归档书目里用过的 `canonical`。** 知识库里已有同名概念页，就复用那个名字；这比自己造一个更准确的名字重要。

**`canonical` 里不要出现斜杠或顿号**（`name` 里可以，作者怎么并列就怎么写）。「嵌入 / 去嵌入」作为作者的说法完全正常，但并列名在脚本里是一个字符串，和任何别的书都对不上，所以 `canonical: 嵌入性`，`aliases: [去嵌入, embeddedness, disembeddedness]`。

**aliases 是连接的地方。** 别的书对同一概念的叫法、原文词、其他译法都往这里放。它和 `canonical` 一起构成这个概念对外的接口，而 `name` 守住对内的忠实。

`concepts` 和 `topics` 等附录二、附录三写完以后回填，不要凭记忆先写。

## 附录一　阅读与引用说明（必有，五六行）

写清：
- 所据版本（出版社、年份、版次/印次），页码均据此版；没有页码的版本写“引文注章节”。
- 阅读方式：顺序通读 / 并行阅读 / 重点阅读；重点阅读时列出精读了哪几章、略读了哪几章。
- 文本来源的特殊情况：扫描版经 OCR、某几页缺文字层、页码靠推断等。
- 引文已与原书逐字核对（verify_quotes.py 全部通过）；如有未能核对的（如他书引文），写明。

这四项是 frontmatter 里 `book` 和 `reading` 两块的人话版本，同一组信息写两遍：一遍给读者，一遍给脚本。两处必须一致，改了一处就改另一处。

**前置部分单独编页时的引用办法。** 很多学术书的丛书序、中文版序、致谢与正文各自从 1 起编页，同一个“14页”会指向两处。遇到这种书，正文引用写成「（14页，序一）」，并在附录一第一条里说明这个约定。附录二的页码列同样加标签（`序一13`）。这个约定要在附录一里写出来，否则日后回查会找错页。

## 附录二　核心概念表（必有，8—20 个概念）

四列，顺序固定：

| 概念 | 作者的界定或用法 | 页码 | 在全书中的位置 |
|---|---|---|---|
| 可能性空间 | “……”（12页）或转述 | 12、45 | 第一章提出，第二章用来定义信息，第三章用来解释组织 |
| 猎身（body shopping） | “……”（8页） | 8、30—32 | 全书的核心机制，第二章详述其运作 |

- **概念**：作者的说法，照抄，不要换成领域通行叫法。外文原词按书里的样子写进括号。归并名不进这张表，它在 frontmatter 的 `canonical` 里。与 `concepts[].name` 逐行对应、顺序一致。
- **页码**：只写数字和分隔符，如 `12、45` 或 `30—32`，不写“第”“页”；全书反复出现、无法列举时写主要的两三处。引自前置部分时加上标签，如 `序一13；1—18`、`序二46—51`。

选概念的标准：全书反复出现、作者专门界定过、或是理解论证的关键。作者没有明确定义的，写“作者未明确定义，从用法看指……”，并标明是转述。

## 附录三　主题引文索引（必有，10—30 条）

按主题分组，而不是按页码排列，这样日后写论文时能按问题找引文。每条一行，格式固定：

```
- “引文”（12页）｜定义｜一句话说明它能用来支撑什么
```

三段用全角竖线 `｜` 隔开，中间那段是**用途标签**，只能取这六个之一，和章节卡片的用途标签是同一套词表：

| 标签 | 什么时候用 |
|---|---|
| 定义 | 作者给某个概念下的界定 |
| 判据 | 判断、区分、衡量某事的标准 |
| 核心命题 | 全书或某章要论证的主张 |
| 方法 | 作者怎么做研究、怎么论证 |
| 例证 | 具体的案例、数据、材料 |
| 作者自述 | 写作动机、立场、学术脉络的夫子自道 |

写全之后是这样：

```markdown
### 附录三　主题引文索引

#### 关于控制的定义
- “……”（12页）｜定义｜作者对控制的基本定义，可用于说明……
- “……”（23页）｜判据｜区分有效控制与无效控制的标准

#### 关于认识论
- “……”（88页）｜核心命题｜……
```

分组标题用 `####`，比“附录三”这一级标题低一级；标题文字与 frontmatter 的 `topics` 逐条对应、顺序一致。主题一般 3—6 个，来自全书主线和你在正文中讨论的问题。

引文优先从章节卡片的候选引文里选，连带把卡片上已经打好的用途标签一起带过来，选出后再跑一遍核对。

## 附录四　延伸阅读（必有，3—8 本/篇）

五列，顺序固定：

| 文献 | 作者 | 出版信息 | 年份 | 与本书的关系 |
|---|---|---|---|---|
| 《礼物》 | 马塞尔·莫斯 | 上海人民出版社 | 2002 | 本书第三章的互惠分析直接接着它讲 |
| The Managed Heart | Arlie Hochschild | University of California Press | 1983 | 可与本书的情感劳动讨论对照，结论相反 |

- **文献**：中文著作用《》，外文著作用原题不加书名号，期刊文章用篇名。
- **与本书的关系**：写实质关系，不写“值得一读”。书中多次对话的著作、正文横向比较用到的著作、后来回应或发展本书观点的研究，各自的关系是不同的，要写出是哪一种。
- 只列检索核实过、确实存在的文献；拿不准的宁可不列。

这一栏从“可选”改成了“必有”，因为跨书归并时它有个额外用处：很多本书共同指向、而你还没读的那一本，就是最该读的下一本。少写一条，这个信号就弱一分。

## 检索来源（可选，放在附录四之后）

第四步检索到的事实本来记在 `notes/sources.md`，归档时也会随笔记一起留下。如果希望这份笔记单独拿出去也能自证，可以在附录四后面加一节「检索来源」，按主题列出链接。它不受格式约束，脚本会跳过。
