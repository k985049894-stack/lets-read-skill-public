# 并行阅读

用户选择“并行阅读”时才用。做法是把正文各章分给几个子任务同时精读，各自写章节卡片；主任务自己读前言、导论、结论，最后汇总卡片、写全书地图。

先跟用户说清代价（第二步提问时已经说过，开始前不用再问）：速度快、主对话更干净，但每个子任务都要从头了解任务，总 token 消耗比顺序阅读高；各章之间的联系要在汇总时补。

如果当前环境没有派发子任务的工具（Agent / Task 之类），告诉用户这里做不了并行，改为顺序通读。

## 1. 分组

- 只分正文章节（chapters.tsv 中 kind 为 chapter 的）。前言、导论、结语、后记由主任务自己读；参考文献、索引不读。
- 按 est_tokens 均衡分组，每组的书本文字一般不超过 8 万 token；整本书据此分成 2—6 组。
- 相邻的章放在同一组，章节不拆开。单章超过 8 万 token 的单独成组，由该子任务分段读。

## 2. 派发前

1. 主任务先读完前言、导论（如有），写好 `notes/book_map.md` 里“全书要回答的问题”的第一版。
2. 建好 `notes/cards/` 目录。
3. 一次性派出所有子任务，让它们同时进行。

## 3. 给子任务的提示（按实际路径填好）

```
你在帮我为《{书名}》（{作者}）写读书笔记，负责精读其中几章并写章节卡片。

工作目录：{WORK}
- chapters/ 下是按章切分的原文，每页前有一行标记：=== [pdf:x] [页:y] ===，“页:”后是印刷页码。
- 全书要回答的问题（主任务读导论后的概括，供参考）：{一两句话}

你负责的章节文件（只读这些）：
{chapters/03_第二章_xxx.txt}
{chapters/04_第三章_xxx.txt}

先读卡片模板：{SKILL_DIR}/references/chapter-card.md，按“精读卡片模板”写。

要求：
1. 用 Read 把每一章完整读完（长章分段读），不要跳读，不要只看开头结尾。
2. 每章写一张卡片，存到 {WORK}/notes/cards/{NN}_{章名}.md，NN 用章节文件名开头的两位数字。
3. 候选引文必须从章节文件中逐字复制，页码取引文前面最近一行标记里的“页:”值；跨页写“a—b页”。不要凭记忆写，不要改字。
4. 卡片只记书里有的内容。你自己的联想只写在最后一栏，并说明是联想。
5. 写完后运行：
   python {SKILL_DIR}/scripts/verify_quotes.py {卡片路径} {WORK}
   修正报告里所有 ⚠️ 和 ❌，直到全部通过。
6. 最后只回复几行：每章一行，写章名、卡片路径、本章核心论点（一句话）。不要把卡片内容贴回来。
```

## 4. 汇总

1. 子任务回复后，逐张读卡片（卡片很短，可以全部读）。
2. 每张卡片抽查一两条候选引文：用 locate.py 搜一下，确认确实在标注的页码。
3. 主任务自己读结语、后记（如有）。
4. 根据卡片写 `notes/book_map.md` 的其余部分：全书主线、各章分工、概念演进、跨章呼应。跨章联系是并行阅读最容易丢的东西，这一步不要省：对卡片里“与其他章的联系”一栏出现的每个概念，用 locate.py 在全书范围内查一遍，补上子任务看不到的呼应。
5. 之后回到 SKILL.md 的第四步，与顺序阅读相同。
